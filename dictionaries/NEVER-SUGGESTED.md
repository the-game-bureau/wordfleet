# Never-suggested words

Words on this list **stay in the dictionary**, so a captain may type one in as a word-ship, but the game
**never suggests or draws them**: not in Build Your Word-Ships suggestions, ↻ / Rebuild All, the example
words on Choose Your AI Captain, or the AI Captain's own fleet.

They still follow "Allow possibly offensive words": a word that is also on a possibly-offensive list can
only be typed in while that switch is on.

The dictionary build scripts (`build-en.js`, `build-hunspell.js`) read this file and mark these words in
each dictionary (`neverSuggest`). Add a word as a list item (one word per line, plurals and spellings
listed separately); a language code in brackets limits it to that language, as in `BANNED.md`
(`en`, `en-US`, `en-GB`, `es`, `de`). Then rebuild the dictionaries as described in `README.md`.
